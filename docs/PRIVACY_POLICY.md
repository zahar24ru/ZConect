# Политика конфиденциальности приложения ZConnect для Windows

**Действует с 02 мая 2026 года.** Версия приложения: 1.0.1.

Каноническая публичная версия: <https://zconn.ru/privacy_win.html>. Этот файл —
зеркало для удобства разработчиков и аудиторов.

## TL;DR

Приложение раз в 5 минут отправляет на сервер автора анонимный heartbeat
(случайный `machine_id`, версия приложения, версия ОС, язык, IP-адрес для
определения страны). Это нужно для подсчёта количества активных установок
и совместимости версий.

**Содержимое сессии** (видео экрана, файлы, буфер обмена, нажатия клавиш)
идёт **напрямую между двумя ПК через WebRTC** и автору не виден.

## 2. Какие данные собирает приложение

Десктопное приложение ZConnect для Windows при работе автоматически отправляет
на сигнальный сервер автора (`connect.zconn.ru`) пакет heartbeat — раз в 5 минут,
пока приложение запущено.

| Поле | Описание | Откуда |
|---|---|---|
| `machine_id` | Случайный UUID, сгенерированный при первом запуске. Не привязан к аппаратным компонентам, не содержит ФИО / email / телефон. | Локально на устройстве |
| `app_version` | Версия приложения, например `1.0.1`. | Скомпилировано в приложение |
| `os_version` | Версия ОС, например `Microsoft Windows 10.0.19045`. | Системное API .NET |
| `os_language` | Язык интерфейса Windows, например `ru-RU`. | Системное API .NET |
| `platform` | Литерал `windows`. | Скомпилировано в приложение |
| IP-адрес | IP устройства, с которого пришёл запрос. | Извлекается из HTTPS-запроса на стороне сервера |
| Страна (`country`) | 2-буквенный код страны по IP через сторонний `ip-api.com`. IP кэшируется на 24 ч в RAM, отдельно от пары `machine_id ↔ country` не сохраняется. | Резолв на нашем сервере |

Приложение для Android дополнительно передаёт `platform=android` и модель
устройства (`device_model`). На Windows эти поля не используются.

## 3. Что приложение НЕ собирает

- **Содержимое сессии удалённого доступа** — видео экрана, аудио, ввод клавиш и мыши, передаваемые файлы и буфер обмена идут **напрямую между двумя ПК через WebRTC P2P** и автору **не доступны**.
- Логины, пароли, коды сессий, секреты устройства — хранятся только локально, шифруются через DPAPI (Windows) или EncryptedSharedPreferences (Android).
- ФИО, email, номер телефона, почтовый адрес, паспортные данные — не запрашиваются и не сохраняются.
- Содержимое адресной книги (имена контактов, коды) — только локально в `%AppData%\ZConect\address-book.json`.
- IMEI, MAC-адреса, серийные номера оборудования — не запрашиваются.

## 4. Цели обработки

- Подсчёт количества активных установок приложения.
- Понимание распределения версий приложения и ОС у пользователей для планирования совместимости.
- Выявление нелегитимного трафика и автоматизированных атак на сигнальный сервер (anti-abuse).

Данные **не используются** для рекламы, профилирования, передачи рекламным
сетям или продажи третьим лицам.

приложение — после удаления новые heartbeat-пакеты на сервер не отправляются.

## 6. Передача данных третьим лицам

Для определения страны пользователя по IP-адресу используется сторонний
публичный сервис [ip-api.com](https://ip-api.com/). На него передаётся только
IP-адрес, никакие иные поля heartbeat-пакета не передаются.

Иным третьим лицам (рекламным сетям, аналитическим системам, рекламодателям)
данные приложения **не передаются**.

Серверная инфраструктура размещается на VPS, физически расположенном
в Российской Федерации.

## 7. Срок хранения

- Записи в БД (`machine_id`, версии, страна, время первого и последнего heartbeat'а) — пока установка активна.
- После прекращения активности (отсутствие heartbeat'а более 12 месяцев) запись подлежит удалению при следующем плановом обслуживании БД.
- Запись может быть удалена досрочно по запросу субъекта (см. раздел 8).
- Резервные копии БД хранятся не более 30 дней и шифруются.

## 9. Защита данных

- Передача данных от приложения на сервер осуществляется через защищённое соединение HTTPS / WSS (TLS 1.2+).
- Доступ к серверной БД ограничен учётной записью администратора и защищён паролем (bcrypt cost 12).
- Административный интерфейс `/admin` доступен только по защищённому соединению, имеет CSRF-защиту и журнал аудита всех действий администратора.
- При попытках несанкционированного доступа к серверу IP-адреса нарушителей блокируются автоматически.

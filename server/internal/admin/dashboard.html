Подозрительные IP

IP адреса которые делают много неуспешных /api/v1/session/join попыток в последние 5 минут. Типичный паттерн брутфорса — множественные попытки с разными login_codes (attacker не знает валидный → перебирает). Per-session lockout не срабатывает в таком сценарии т.к. login_code не матчит ни одну сессию.

Реагировать: проверить в логах pattern (intervals, User-Agent), при уверенности — добавить в IP блокировки вкладке рядом. Автобан НЕ делается — NAT/мобильные сети могут иметь много legitimate users за одним IP.

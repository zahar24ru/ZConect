Цель для ZConect

Сделать модуль, который ощущается как Total Commander по удобству, как FileZilla/WinSCP по стабильности и как TeraCopy/FastCopy по скорости и контролю ошибок.

Total Commander

Двухпанельный файловый менеджер
  • Супер-быстрая навигация (две панели + горячие клавиши)
  • Пакетные операции, синхронизация каталогов
  • Удобная работа с архивами как с папками
Взять в ZConect: 2-панельный режим, «F5/F6»-логика копирования/перемещения, быстрый фильтр и массовые операции.

FileZilla

FTP/SFTP клиент
  • Очередь передач с приоритетами
  • Надёжный retry и докачка
  • Отдельные вкладки для локальной/удалённой FS
Взять в ZConect: мощная очередь, статусы по каждому файлу, автоповторы и «resume after reconnect».

WinSCP

SFTP/SCP/FTP клиент
  • Сильная безопасность + проверка ключей
  • Скрипты/автоматизация задач
  • Синхронизация папок с правилами
Взять в ZConect: профиль подключения, fingerprint trust, синхронизация и CLI-режим для авто-задач.

TeraCopy

Копирование в Windows
  • Пауза/продолжить копирование
  • Контроль конфликтов и пропуск ошибок
  • Проверка целостности (hash)
Взять в ZConect: «умный» conflict resolver, верификация после передачи, понятные отчёты об ошибках.

FastCopy

Высокоскоростное копирование
  • Максимум скорости на больших объёмах
  • Тонкая настройка буферов/потоков
  • Надёжный лог и проверка
Взять в ZConect: режимы speed/reliability, профили оптимизации под LAN/Internet.

Syncthing

P2P синхронизация
  • End-to-end шифрование и P2P
  • Версионирование и watch папок
  • Устойчивость к обрывам сети
Взять в ZConect: «папка под наблюдением», дельта-синк и безопасный P2P-канал.

Рекомендуемый roadmap для дополнения ZConect File Transfer

v0.1 MVP: загрузка/скачивание файлов, очередь, пауза/resume, drag&drop, прогресс по каждому файлу.
v0.2 Stability: автоповторы, контроль таймаутов, верификация SHA-256, нормальный журнал ошибок.
v0.3 Pro UX: двухпанельный режим, массовые операции, фильтры, шаблоны путей, горячие клавиши.
v0.4 Smart Sync: синхронизация папок, сравнение по хэшу/mtime, dry-run перед применением.
v0.5 Secure P2P: end-to-end, NAT traversal, fallback relay, шифрованные профили подключения.
